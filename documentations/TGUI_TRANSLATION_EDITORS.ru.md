# TGUI: инструкция для редакторов перевода (без программирования)

Этот документ для тех, кто правит тексты интерфейса, но не пишет код.

## Что вы редактируете

Основной файл русского интерфейса:

- `tgui/packages/tgui/interfaces/locales/ui.*.ru.json`

Английский оригинал (для смысла):

- `tgui/packages/tgui/interfaces/locales/ui.*.en.json`

Важно:

- меняем только текст справа от ключа
- ключи слева (`"ui...."`) не переименовываем и не удаляем

## Базовый формат строки

```json
"ui.example.key": "Текст перевода",
```

Где:

- `"ui.example.key"` — служебный ключ (не трогать)
- `"Текст перевода"` — ваш перевод (можно менять)

## Как исправить плохой перевод

1. Найдите проблемный текст в игре.
2. Найдите соответствующий ключ:

- если в интерфейсе показался текст вида `ui.something.key`, это и есть ключ
- если ключ не виден, попросите разработчика дать ключ

3. Откройте соответствующий `ui.*.ru.json` и найдите ключ поиском (`Ctrl+F`).
4. Исправьте только русское значение.
5. Сохраните файл.

## Что нельзя делать

- не менять имя ключа
- не удалять запятые в конце строк
- не добавлять комментарии (`// ...`) в JSON

## Качество перевода: короткий чеклист

Перед сохранением проверьте:

1. Смысл соответствует английской строке в соответствующем `ui.*.en.json`.
2. Текст естественный для UI на русском.
3. Нет транслита и мусора кодировки.
4. Нет лишних пробелов в начале/конце строки.
5. Служебные вставки сохранены, если они есть:

- `%s`, `{0}`, `{name}`, `{{value}}` и т.п. (если встречаются в строке)

## Частые проблемы и как исправлять

1. Видите `????` или `пїЅ...`:

- замените строку нормальным русским текстом по смыслу из соответствующего `ui.*.en.json`

2. В русском остался английский (`"Open"`, `"Status"`, ...):

- переведите на русский, если это не имя бренда/название системы

3. Слишком буквальный или кривой перевод:

- переформулируйте естественно, сохраняя исходный смысл. Убедитесь что оно сейчас неадекватно смотрится, перед редакцией.

## Как не сломать файл

После правок:

1. Убедитесь, что строка в формате:

- `"ключ": "значение",`

2. Проверьте подсветку ошибок в редакторе (VS Code показывает ошибки JSON).
3. Если есть ошибка JSON, чаще всего причина:

- пропущена запятая
- лишняя/пропущенная кавычка
